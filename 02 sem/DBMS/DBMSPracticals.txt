6. Savepoint, Commit, and Rollback

-c) Create Tables

    RollNo INT,

    RollNo INT PRIMARY KEY,
    Name VARCHAR(50) NOT NULL,

- d) View All Tables

-e) Insert, Update, Delete Records
Insert :
INSERT INTO Student VALUES (1, 'Adesh', 22);

UPDATE Student
SET Age = 23
WHERE RollNo = 1;

WHERE RollNo = 1;

-f) Savepoint, Commit, and Rollback
Savepoint :
SAVEPOINT sp1;

Commit :
COMMIT;

Rollback :
ROLLBACK TO sp1;

6. For a given set of relation schemes, create tables and perform:

1. Simple Queries
2. Simple Queries with Aggregate Functions
3. Queries with Aggregate Functions using GROUP BY and HAVING Clause
Answer:

-Create Table
CREATE TABLE Employee(
    EmpID INT PRIMARY KEY,
    Name VARCHAR(50),
    Department VARCHAR(20),
    Salary INT
);

-Insert Data
INSERT INTO Employee VALUES
(1, 'Adesh', 'IT', 30000),
(2, 'Rahul', 'HR', 25000),
(3, 'Priya', 'IT', 40000),
(4, 'Neha', 'HR', 35000);

-1. Simple Query
SELECT * FROM Employee;

-2. Aggregate Function Query
SELECT AVG(Salary) AS AverageSalary
FROM Employee;

-3. GROUP BY Query
SELECT Department, SUM(Salary) AS TotalSalary
FROM Employee
GROUP BY Department;

-4. GROUP BY with HAVING Clause
SELECT Department, AVG(Salary) AS AvgSalary
FROM Employee
GROUP BY Department
HAVING AVG(Salary) > 30000;

Result: Simple queries, aggregate functions, and GROUP BY with HAVING clause are executed successfully on the Employee table.

8. Writing SQL and PL/SQL queries to retrieve information from the database.
Answer:
-Create Table
CREATE TABLE Employee(
    EmpID NUMBER,
    Name VARCHAR2(50),
    Salary NUMBER
);

-Insert Data
INSERT INTO Employee VALUES(1, 'Adesh', 30000);
INSERT INTO Employee VALUES(2, 'Rahul', 25000);
INSERT INTO Employee VALUES(3, 'Priya', 40000);

-SQL Query to Retrieve Information
SELECT * FROM Employee;

-PL/SQL Query to Retrieve Information
DECLARE
    v_name Employee.Name%TYPE;
    v_salary Employee.Salary%TYPE;
BEGIN
    SELECT Name, Salary
    INTO v_name, v_salary
    FROM Employee
    WHERE EmpID = 1;

    DBMS_OUTPUT.PUT_LINE('Name: ' || v_name);
    DBMS_OUTPUT.PUT_LINE('Salary: ' || v_salary);
END;

Result: Information is retrieved successfully from the database using both SQL and PL/SQL queries.

9. For a given set of relation schemes, create tables and perform the following:
1. Inner Join
2. Outer Join
3. Subqueries with IN Clause
4. Subqueries with EXISTS Clause
Answer:
-Create Table
CREATE TABLE Department(
    DeptID INT PRIMARY KEY,
    DeptName VARCHAR(50)
);

CREATE TABLE Employee(
    EmpID INT PRIMARY KEY,
    EmpName VARCHAR(50),
    DeptID INT,
    FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
);

-Insert Data
INSERT INTO Department VALUES (101, 'IT');
INSERT INTO Department VALUES (102, 'HR');

INSERT INTO Employee VALUES (1, 'Adesh', 101);
INSERT INTO Employee VALUES (2, 'Rahul', 102);
INSERT INTO Employee VALUES (3, 'Priya', 101);

-1. Inner Join
SELECT E.EmpID, E.EmpName, D.DeptName
FROM Employee E
INNER JOIN Department D
ON E.DeptID = D.DeptID;

-2. Outer Join (Left Outer Join)
SELECT E.EmpID, E.EmpName, D.DeptName
FROM Employee E
LEFT OUTER JOIN Department D
ON E.DeptID = D.DeptID;

-3. Subquery with IN Clause
SELECT *
FROM Employee
WHERE DeptID IN
(
    SELECT DeptID
    FROM Department
    WHERE DeptName = 'IT'
);

-4. Subquery with EXISTS Clause
SELECT *
FROM Department D
WHERE EXISTS
(
    SELECT *
    FROM Employee E
    WHERE E.DeptID = D.DeptID
);

Result: Inner Join, Outer Join, and Subqueries using IN and EXISTS clauses are executed successfully.
