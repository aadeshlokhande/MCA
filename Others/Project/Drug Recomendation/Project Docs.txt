AI-Based Drug Recommendation System
Academic Clinical Decision-Support & Medication Safety Screening Web Application

The AI-Based Drug Recommendation System has been fully designed, developed, integrated, and verified. The application is built using Python 3.12, Django 6.1, NumPy, Joblib, and ReportLab, styled with an Apple Liquid Glass (Light Theme) aesthetic.

Clinical Disclaimer: This system is an academic clinical decision-support research prototype. Machine learning predictions are differential statistical approximations and must never replace qualified clinical diagnosis, laboratory testing, or in-person physician evaluation, nor does the system autonomously prescribe medications.

2. Key Modules & Functional Workflows
Module 1: Authentication and Authorization
Custom User Model (accounts.User) with three roles: PATIENT, DOCTOR, and ADMIN.
Role Redirection (role_redirect): Users are automatically redirected to their dedicated workspace upon sign-in.
Patient Record Isolation: Strict permission checks prevent any patient from accessing another patient's assessments or records.
Module 2: Patient Profile and Medical History
Stores patient demographics (Age, Gender, Blood Group, Pregnancy status, Emergency contacts).
Interactive modals and forms to manage Documented Allergies, Ongoing Medications, and Past Medical Conditions.
Module 3: Symptom Checker & NLP Engine
Searchable catalog of 66 clinical symptoms across 9 anatomical and systemic categories.
Real-time client-side search filter and interactive glass chips.
Clinical NLP Parser: Tokenizes free-text complaints, matches synonyms, detects negations (e.g., "no cough", "denies chest pain"), and flags emergency red-flag triggers (e.g., severe chest pain, dyspnea).
Mandatory Confirmation Screen: Allows patients to review reported symptoms before launching the ML inference pipeline.
Module 4: Machine Learning Disease Prediction Pipeline
Vectorized training and comparison of three distinct classifiers on held-out test splits without data leakage:
Decision Tree (CART with Gini Impurity)
Random Forest (Ensemble with Feature Subsampling & Bagging)
Multinomial Naive Bayes (Laplace-smoothed Log-Likelihood)
Computes Accuracy, Weighted Precision, Recall, F1-Score, and Confusion Matrix.
Serializes the active pipeline using Joblib (ml_models/active_model.joblib).
Live inference engine (ml_engine.predictor) provides calibrated differential probabilities for primary and secondary conditions.
Module 5 & 6: Medicine Information & Drug Safety Screening Engine
Curated reference catalog of essential medicines citing the WHO Model List of Essential Medicines and FDA monographs.
Multi-layered algorithmic safety screening checks:
Allergy Cross-Reactivity Check: Evaluates active ingredients and chemical classes against patient allergies.
Drug-Drug Interaction Check: Compares candidate medicines against active medications.
Medical History Contraindications Check: Evaluates chronic conditions against drug contraindications (e.g., NSAIDs in peptic ulcer disease).
Age Restrictions: Enforces pediatric and geriatric minimum/maximum approved age thresholds.
Pregnancy Safety: Enforces FDA Pregnancy Categories (C, D, X) for pregnant patients.
Duplicate Active Ingredients: Prevents accidental cumulative toxicity.
Safety Suppression: Automatically marks high-risk candidate recommendations as SUPPRESSED (is_suppressed=True), presents prominent red alert warnings, and prohibits self-medication guidance.
Module 7: Patient Dashboard
Displays 4 real-time health metric widgets (Total Assessments, Active Medications, Logged Allergies, Chronic Conditions).
Recent symptom assessments table with direct links to full results and PDF reports.
Profile and allergy/medication summary cards.
Module 8: Doctor Dashboard & Clinical Triage Queue
Physician workspace with triage filters (All, Pending Review, Reviewed).
Clinical Review Workspace:
Complete view of patient history, allergies, reported symptoms, ML differential diagnoses, and safety alerts.
Form to record independent clinical diagnostic impressions, endorse/modify medicines, formulate direct patient instructions, and provide follow-up advice.
Authenticated electronic sign-off with license number and timestamp.
Module 9: Medical History & Clinical PDF Reports
Downloadable clinical-grade PDF reports generated dynamically with ReportLab.
Formatted tables with patient demographics, symptom duration, differential probabilities, screened medicine statuses, and physician sign-off blocks.
Module 10: Admin Panel & ML Analytics Dashboard
Django Admin console (/admin/) for reference data curation.
Custom analytics dashboard with Chart.js comparative performance bar chart, confusion matrix visualizer, dataset provenance metrics, and immutable security audit logs.
Module 11 & 12: Notifications, Safety Guidance & Audit Logging
In-app notification center with unread counters and mark-as-read AJAX triggers.
Immutable audit log capturing logins, logouts, registrations, ML runs, safety screenings, doctor reviews, and unauthorized access attempts.
3. Apple Liquid Glass UI Design

The entire user interface consistently applies the Apple Liquid Glass Light Theme:

Palette: Primary background #F5F8FC, secondary background #EEF3F8, accent blue #3984E8, teal accent #54B7C5, dark slate text #172B45, and muted text #6B7C93.
Surfaces: Translucent frosted panels with backdrop-filter: blur(16px), soft layered shadows (0 8px 24px rgba(31, 38, 135, 0.06)), and delicate semi-transparent white borders (1px solid rgba(255, 255, 255, 0.85)).
Interactive Elements: Pill-shaped gradient action buttons, interactive symptom chips that turn blue on selection (and red for red-flag symptoms), responsive desktop sidebar, and mobile offcanvas navigation.

6. How to Run the Application
bash
# 1. Activate the virtual environment
source venv/bin/activate
# 2. (Optional) Re-seed data or train ML models if needed:
# python manage.py seed_medical_data
# python manage.py train_models
# 3. Start the Django development server
python manage.py runserver

Open your browser at http://127.0.0.1:8000/ to explore the application.
