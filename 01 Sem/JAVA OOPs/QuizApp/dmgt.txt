Q. 1
Power set of a set with 4 elements has:
a) 4             
b) 8                 
c) 16            
d) 32

Answer : c) 16

Q. 2 
n(A ∪ B) = n(A) + n(B) – n(A ∩ B) is:
a) Inclusion Exclusion Principle            
b) De Morgan’s Law
c) Partition                                               
d) Complement Rule

Answer : a) Inclusion Exclusion Principle

Q. 3 
Negation of (P ∧ Q) is:
a) ¬P ∧ ¬ Q                       
b) ¬P ∨ ¬ Q         
c) ¬P ∧ Q                          
d) P ∨ Q

Answer : b) ¬P ∨ ¬Q

Q. 4
Euclid algorithm repeatedly uses:	
a) Addition                      
b) Subtraction  
c) Division remainder     
d) Multiplication

Answer : c) Division remainder

Q. 5
If a | b and b | c, then:
a) a|c                             
b) c|a              
c) a=c                          
d) No relation

Answer : a) a | c

Q. 6
A bijective function is:
a) Injective only                                         
b) Surjective only
c) Both injective & surjective                    
d) Constant

Answer : c) Both injective & surjective

Q. 7 
An equivalence relation is:  
a) Reflexive + symmetric               
b) Symmetric + transitive
c) Reflexive + symmetric + transitive       
d) None

Answer : c) Reflexive + symmetric + transitive

Q. 8
R = {(1,1),(2,2),(3,3)} is:
a).Symmetric                              
b). Reflexive on {1,2,3}
c). Both                                       
d) None

Answer : c) Both

Q. 9
A graph G=(V,E) requires:
a) Vertices only                                 
b) Edges only
c) Both vertices and edges              
d) Weights

Answer : c) Both vertices and edges

Q. 10
Path means:
a) Repeated vertices allowed         
b) All vertices distinct
c) Only edges distinct                  
d) No vertex

Answer : b) All vertices distinct

Q. 11
A graph with multiple edges is:
a)Simple         
b. Multigraph           
c. Tree              
d Subgraph

Answer : b) Multigraph

Q. 12
The Well-Ordering Principle states that every non-empty set of __________ contains a least element.
a)integers                       
b). natural numbers  
c)  real numbers             
d) rational numbers

Answer : b) Natural numbers
